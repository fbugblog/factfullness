SELF-STUDY / 日本語の自習教材 14 / 17

第12章：総合演習

以下はすべて教材独自の架空の記事・広告・職場データです。実在の事件、会社、商品の評価ではありません。各ケースで主張、根拠、不明点、代替説明、次の行動の順に答えます。解答は付録Tです。

T1：ニュースの主張と根拠

「市内の自転車事故が昨年40件から今年60件に急増。自転車は危険なので利用をやめるべきだ」という記事があります。期間は両年とも1〜12月、地域は同じ市、事故は警察に届けられた人身事故の件数とします。走行回数は昨年200万回、今年400万回という架空の推計です。

  1. 件数の変化率と100万回当たりの事故率を求める。
  2. 記事の事実、因果や評価の主張を分ける。
  3. 事故率が下がれば対策は不要と言えるか。恐怖・ネガティブ・過大視の観点を含めて説明する。
  4. 公開記事で同様の主張を検証するとしたら、元の集計表と推計方法の何を調べるか。

T2：広告の数字

「利用者の90%が効果を実感。今夜で半額終了」という広告です。対象は購入者1000人、アンケート回答者100人、そのうち90人が効果を実感したという架空データ。質問文、未回答理由、比較対象、健康状態の変化の測定方法は掲載されていません。

  1. 90%の分母は何か。全購入者について同じ割合と言えるか。
  2. 回答しなかった900人全員が実感していない場合と、全員が実感した場合の全体割合を求める。これは推定値か、それとも仮定による範囲か。
  3. 効果の因果関係を判断するために必要な情報を二つ挙げる。
  4. 焦り本能とパターン化本能が重なる点を説明し、購入前に取る行動を決める。

T3：職場データから改善策

同じ四半期に、部署Aは処理1000件・ミス20件、部署Bは処理200件・ミス8件でした（架空データ）。Aは自動入力あり、Bは手入力で複雑な案件を担当します。「Aはミス件数が多いので責任者を交代しよう」という提案が出ました。

  1. 両部署の率を計算し、件数での比較と違いを説明する。
  2. 率だけで担当者の能力を比較できない理由を述べる。
  3. 個人の責任確認と、仕組みの原因分析を分けた調査案を書く。
  4. 小さく試せる改善策と、効果・副作用を測る指標を挙げる。

T4：複数の本能が重なる場面

「この地域は昔から新技術に弱い。導入が半年間毎月5ポイント増えたから、このペースで100%になる。遅れる前に今日、全社導入を決めるべきだ」。これは架空の発言です。

宿命・直線・焦り本能が関わる箇所を特定し、対象、期間、指標の定義、予測の仮定、解約可能性を確認する質問を作ってください。導入率の改善と、利用できず困っている人への支援を両立する提案も書きましょう。

自己評価

各ケースを「主張の切り分け」「計算と分母」「代替説明と限界」「具体的な次の行動」の四観点で、それぞれ0点（未記入）、1点（一部）、2点（根拠つき）と評価します。合計点で他人と競うのではなく、抜けた手順を一つ選んでやり直してください。
