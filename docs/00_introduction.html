SELF-STUDY / 日本語の自習教材 02 / 17

はじめに：なぜ、私たちの世界認識はずれるのか

この教材で身につけること

私たちは目立つ事件、過去の経験、分かりやすい説明を使って素早く判断します。それは生活に必要ですが、情報の届き方が偏っていると世界の見方もずれます。間違いを個人の知性のせいにするのではなく、確認の手順を身につけましょう。

この教材では「観察したこと」「そこから考えたこと」「まだ分からないこと」を分けて記録します。目的は世界についての正解を暗記することではなく、判断を更新できるようになることです。

ファクトフルネスとは

本書の考え方を学ぶ入口として、事実に基づいて世界を捉え、劇的な思い込みを点検する姿勢を扱います。10の本能という枠組みと日本語の名称は本書を学ぶために用いています。心理の働きを診断する医学的分類ではありません。

本書由来の枠組み：分断、ネガティブ、直線、恐怖、過大視、パターン化、宿命、単純化、犯人捜し、焦り。

教材独自の補足：統計の計算、職場や広告の事例、確認手順、すべてのクイズと演習。本書の本文を照合できていないため、逐語引用やページ番号、書籍中のクイズは掲載しません。すべての数値例は明記した架空データです。

学習前の自己診断クイズ

以下はすべて架空データです。正誤に加えて理由と確信度（低・中・高）を書いてください。解答は付録Iです。

  1. 苦情が10件から20件に増えた。利用者数を知らなくても苦情率は倍だと言える。（正／誤）
  2. 平均給与が高い会社では全員の給与が他社より高い。（正／誤）
  3. 商品を買った人は買わない人より健康だった。商品の健康効果が証明された。（正／誤）
  4. 悪い状態であることと、以前より改善していることは両立する。（正／誤）
  5. 一日100人増えている利用者は一年後も必ず同じペースで増える。（正／誤）

教材の使い方

各章のケースを読んだら、解説へ進む前に一行だけ判断を書きます。選択問題、短い記述、実践課題の順に取り組み、最後に付録の解説で照合してください。正解だったかに加え、分母や比較条件を実際に確認したかを振り返ります。

実践で使う記事や職場データは、公開可能な範囲で扱います。個人情報や機密情報を記録に含める必要はありません。資料にアクセスできない場合は、分からない点を明示すること自体が適切な成果です。

改善のデータは現在の被害や一人ひとりの苦境を否定しません。全体、集団、個人のどの水準について話しているかを毎回確かめます。
