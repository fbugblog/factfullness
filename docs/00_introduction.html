SELF-STUDY / 日本語の自習教材 02 / 17

はじめに：世界を見る眼鏡を、かけ直す

朝、ニュースを読みました。戦争、災害、不正。世界は毎日、悪くなっているように見えます。その一方で、遠い国の普通の家庭が、昨日より少し便利に暮らせるようになったことは、なかなか見出しになりません。

もし私たちが、世界を映した一枚の写真だと思っているものが、目立つ場面だけを集めたアルバムだったら。そこから作った世界像には、どんな偏りが生まれるでしょうか。

『FACTFULNESS』を学ぶ入口は、「もっと数字を覚えなさい」という説教より、この問いにあります。知識が少ないから間違えるだけではなく、持っている知識が古かったり、情報の受け取り方に癖があったりする。だから、物知りでも世界を見誤ることがあるのです。

世界を明るく塗るのではなく、解像度を上げる

この本から学びたいのは、何でも良いニュースに読み替える方法ではありません。貧困、暴力、病気などの深刻な問題を見ながら、同時に、どこでどんな変化が起きてきたかを確かめる姿勢です。

たとえば、まだとても苦しい状態にあることと、以前より良くなっていることは両立します。逆に、ある面が改善していても、別の問題が悪化していることもあります。どちらか一方の大きな物語だけで世界を説明しない。この姿勢が、日常の判断にも役立ちます。

教材では、その手がかりとなる「10の本能」をたどります。二つに分けたくなる、悪い方へ考える、線を延ばす、怖さに引かれる、大きな数に圧倒される、ひとまとめにする、変わらないと思う、一つの説明に頼る、犯人を探す、急いで決める。どれも、他人だけの癖ではなさそうです。

まずは、小さな思い込みの実験

以下は本書のクイズの転載ではなく、この教材独自の問題です。数値はすべて架空データ。正誤に加え、「なぜそう思うか」を一行書いてみてください。解答は付録Iにあります。

  1. 苦情が10件から20件に増えた。利用者数を知らなくても苦情率は倍だと言える。（正／誤）
  2. 平均給与が高い会社では、全員の給与が他社より高い。（正／誤）
  3. 商品を買った人は買わない人より健康だった。商品の健康効果が証明された。（正／誤）
  4. 悪い状態であることと、以前より改善していることは両立する。（正／誤）
  5. 一日100人増えている利用者は、一年後も必ず同じペースで増える。（正／誤）

分からない問題があっても構いません。「何が分かれば答えられるか」を言えることも、大切な力です。五問を読み終えたら、自分の確信の強さを、低・中・高でメモしておきましょう。最後にもう一度戻ってきます。

読み方は、散歩に近くていい

最初に基礎編を読み、その後は気になった章から入っても大丈夫です。一章は20分ほど。最初の場面を読み、少し考え、解説で見方を増やす。最後に問題を一つ解く。それくらいで進められます。

「この本能が働いているぞ」と、他人を分類するために使うと、学ぶ楽しさが薄れてしまいます。まずは自分が驚いたとき、怒ったとき、急ぎたくなったときに思い出してください。間違いを一つ見つけるたび、世界の見え方を少し修正できる、と考えてみましょう。

学び終わったときの目標は、10の名前を唱えられることだけではありません。「この数字の分母は？」「いつと比べた話？」「ほかの説明は？」と、立ち止まる問いを持てることです。
